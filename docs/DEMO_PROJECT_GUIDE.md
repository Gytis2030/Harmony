# Demo Project Guide

## Purpose

This guide helps you set up a realistic demo project to walk producers, artists, or potential beta users through Harmony's core workflow. The goal is not to show every feature — it's to show the one thing Harmony does uniquely well: collaborative stem review with real-time feedback, versioning, and presence.

A good demo creates a believable story: a producer sharing a draft mix with a collaborator and getting meaningful feedback without emailing files back and forth.

---

## Recommended Demo Project

**Project name:** `Midnight Draft — Demo Session`

This name sets the right context. It sounds like a real in-progress session, not a toy example.

---

## Recommended Stems to Upload

Upload these stems in order. They map to a plausible pop/electronic production:

| Stem name      | Notes                                   |
| -------------- | --------------------------------------- |
| Drums          | Kick + snare + cymbals printed together |
| Bass           | Bass synth or bass guitar DI            |
| Lead Vocal     | Main vocal, not tuned or mixed yet      |
| Backing Vocals | Harmonies or ad-libs                    |
| Synths         | Pads, leads, or arpeggios               |
| Reference Mix  | A stereo bounce of the current mix      |

Upload the Reference Mix last so it sits at the top of the list and can be used to sanity-check the individual stems during playback.

If you do not have real stems, use any short royalty-free audio files (even test tones). The demo is about the workflow, not the music quality.

---

## Recommended Comments to Create

Add these comments at different points on the timeline after uploading stems. Spread them out — don't cluster all at one timestamp.

1. "Can we bring the drums up at the drop?"
2. "Vocal feels slightly loud here."
3. "This section could use more energy."
4. "Great moment — keep this."
5. "Can we try a drier vocal in this section?"

Add replies to at least one comment to demonstrate the thread view. For example, reply to comment 1 with: "Agreed — try +2 dB on the drum bus."

---

## Recommended Versions to Create

Create these versions after uploading stems and adding comments. Each version represents a meaningful milestone in the mix:

| Version name         | Purpose                                              |
| -------------------- | ---------------------------------------------------- |
| Rough Mix v1         | The initial unpolished bounce you sent to the client |
| Vocals Up            | After adjusting the vocal level                      |
| Client Notes Applied | After incorporating the first round of feedback      |
| Final Review         | Ready for mastering sign-off                         |

After creating all four, demonstrate restoring an earlier version to show that no work is ever lost.

---

## Recommended Invite and Share Link Tests

Before the demo, perform these tests in a private browser or a second account:

1. **Invite an editor** — Invite a second email as Editor. Confirm they can upload a stem and leave a comment.
2. **Invite a commenter** — Invite a third email as Commenter. Confirm they can comment but not upload.
3. **Invite a viewer** — Invite a fourth email as Viewer. Confirm they can play back stems but not comment.
4. **Share link (viewer)** — Generate a Viewer share link. Open it in an incognito window. Confirm playback works with no sign-in required if anonymous links are enabled, or that it prompts sign-in otherwise.
5. **Share link (commenter)** — Generate a Commenter share link. Open it and leave a comment. Confirm it appears in the activity feed.

## How to Walk Someone Through the Demo

Keep the walkthrough under 10 minutes for a first impression. Hit these beats in order:

1. **Dashboard** — "This is where all your projects live. You can archive finished ones."
2. **Open the demo project** — "This is what a project looks like. You can see all the stems in the timeline."
3. **Playback** — Hit play. Mute and solo one stem. Adjust volume. "The whole team hears the same playback state."
4. **Comment** — Click on the timeline, leave a comment. "Comments are pinned to a timestamp, so everyone knows what moment you're talking about."
5. **Presence** — If you have a second window open, show the avatar in the top bar. "Your collaborators appear here live."
6. **Versions** — Open the version history. "Every save is preserved. You can restore any point in the project history."
7. **Invite** — Show the invite modal. "You control who can edit, comment, or just listen."
8. **Activity feed** — Show the feed. "Everything that's happened on this project is logged here."

End with: "The next step for you would be inviting your collaborator and uploading your own stems."
